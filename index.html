Documentation

From download
to first use.

Each repository is the source of truth for its supported versions and configuration. This short path gets a plugin onto a test server safely.

  1. 01

    Choose a plugin

    Open its repository and confirm the required Minecraft, Java, server-platform, and dependency versions.

  2. 02

    Download the release

    Get the latest packaged jar from GitHub Releases. Do not run source archives as server plugins.

  3. 03

    Install while stopped

    Stop the server, place the jar and required dependencies in plugins/, then start it once.

  4. 04

    Read and verify

    Review generated configuration, commands, and permissions, then follow the README’s first-use check on a test server.
