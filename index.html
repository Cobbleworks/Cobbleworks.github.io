Installing a plugin

A few things to check first.

There is no shared Cobbleworks installer. Every repository documents its own supported versions, dependencies, commands, permissions, and configuration.

  • Use the release jar.Download the packaged .jar from GitHub Releases—not the automatically generated source archive.
  • Check compatibility.Confirm the Minecraft, Java, Paper or Spigot, and dependency versions listed in that plugin’s README.
  • Install with the server stopped.Place the plugin and required dependencies in plugins/, start once, then review the generated configuration.
  • Test before updating production.Keep backups and verify an update on a copy of the server when the plugin affects worlds, inventories, or player data.

Versions differ between projects

Some plugins support Java 17 and a broad range of Minecraft versions; newer projects require Java 21 or 25 and Paper-specific APIs. The badge on a card is only a quick reference. The repository README and latest release notes are definitive.
