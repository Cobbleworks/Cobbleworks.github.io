How Cobbleworks works

  • One plugin, one purpose

    No bundles and no shared core library. Add the plugins your server needs and leave the rest out.

  • Requirements per release

    Every page states the server software, Minecraft build target, Java version, and dependencies of the current release.

  • Documented commands

    Commands, permissions, and configuration keys are listed on each plugin page and in the tagged README.

  • Issues tracked in public

    Report bugs and propose changes in the repository of the plugin concerned, where everyone can follow them.

Frequently asked questions

Which server software do the plugins support?

All plugins run on Paper. Several also support Spigot; each plugin page and the compatibility table state the platform of the current release.

Which Java version do I need?

Between Java 17 and Java 25, depending on the plugin. Plugins built for Paper 26.2 need Java 25.

Are the plugins free to use?

Yes. All released plugins are MIT licensed. You can run them on any server, read the source, and adapt them.

Do any plugins depend on each other?

Blood Moon 2.0 requires Blockfolk 1.4.0 or newer. Custom Jukebox requires NoteBlockAPI. Every other plugin installs on its own.

How do I update a plugin?

Read the release notes, stop the server, and replace the old JAR in plugins/ with the new one. Keep a backup of your world and plugin data before upgrading.

Where do I report a bug?

Open an issue in the repository of the plugin concerned. Include the plugin, server, and Java versions, plus the relevant console output.
