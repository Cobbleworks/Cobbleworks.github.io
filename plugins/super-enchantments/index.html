Super Enchantments

Take enchantments further.

What it does

Vanilla enchantments can be applied at levels up to 255. Custom enchantments use persistent item data and configurable cooldowns. Tab completion suggests valid enchantments for the held item.

  • Enhanced Vanilla Enchanting
  • Nine Custom Enchantments
  • Smart Item Compatibility
  • Context-Aware Tab Completion

Features

  • Enhanced Vanilla Enchanting

    Apply vanilla enchantments at levels 1..255 (unsafe application enabled)

  • Nine Custom Enchantments

    Custom combat/utility enchantments with trigger events, particles, sounds, and per-player cooldown behavior

  • Smart Item Compatibility

    Automatic compatibility checking ensures only valid enchantments are suggested for the item currently held in hand

  • Context-Aware Tab Completion

    Intelligent tab completion shows only applicable enchantments based on the held item type

  • Configurable Cooldowns

    Built-in cooldown system with optional chat notifications when a custom enchantment is on cooldown

  • Persistent Storage

    Custom enchantments are stored using Minecraft's persistent data container system for reliable cross-restart persistence

  • Visual Feedback

    Particle effects, sounds, and visual indicators play when custom enchantments activate

Installation

  1. 1

    Check your server

    Run Spigot / Paper with Java 21 or newer, built for Minecraft 1.20.4. No other plugins are required.

  2. 2

    Add the JAR

    Stop the server, download Super-Enchantments-1.0.3.jar, and place it in plugins/. When upgrading, replace the previous JAR.

  3. 3

    Start and configure

    Start the server and check the console. Review the generated configuration with the release documentation.

First command
/enchantlist

Hold the item you want to enchant and list the enchantments that apply to it.
