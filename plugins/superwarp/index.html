Features

  • Native warp dialog

    Warp destinations appear in a three-column Dialog grid.

  • Named destinations

    Create, overwrite, and remove case-insensitive warp names.

  • Permission controls

    Separate permissions for using, setting, and removing warp points.

Installation

  1. 1

    Get the source

    Clone Superwarp from GitHub.

  2. 2

    Build the JAR

    Follow the build instructions with Java 25 and Maven 3.9 or newer.

  3. 3

    Install

    Place the built JAR in the plugins/ directory of a Paper 26.2 server and start it.

First command
/superwarp

Open the native warp dialog. Operators create a destination with /superwarp set <name>.

Commands3

CommandDescription
/superwarp or /swarpOpen the warp dialog
/superwarp set <name>Create or overwrite a warp at your position
/superwarp remove <name>Remove a warp

Permissions3

PermissionDefault
superwarp.useEveryone
superwarp.setOperators
superwarp.removeOperators
