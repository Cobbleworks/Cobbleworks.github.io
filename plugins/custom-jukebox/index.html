What it does

NoteBlockAPI must be installed separately. Signs can toggle, pulse, or ignore redstone. Custom song-bound records preserve their identity through persistent item data.

  • Folder-aware song browser
  • Personal playback
  • Jukebox signs
  • Three redstone modes

Features

  • Folder-aware song browser

    Subdirectories become navigable folders in the in-game GUI

  • Personal playback

    Play or stop a song without creating a world jukebox

  • Jukebox signs

    Store the selected song, volume, looping, and redstone mode directly on a sign

  • Three redstone modes

    Toggle, pulse, or ignore external redstone power

  • Area redstone triggers

    Levers, buttons, plates, and dust near a sign trigger it, so one switch can drive several signs

  • Now-playing controls

    Progress bar, pause/resume, queue, shuffle, loop, and per-player volume in the browser

  • Registered-sign index

    List configured signs and their locations with an admin command

  • Lazy song loading

    Scan metadata without keeping every complete song in memory

  • Action-bar status

    Show the active personal song while it is playing

  • Live reload

    Rescan the song library without restarting the server

  • Persistent custom records

    Create a physical record for any indexed song and play it in a vanilla jukebox

  • Random intact disc artwork

    Each created record uses a randomly selected full music-disc icon; the cracked 11 disc and disc fragments are excluded

  • Block lifecycle support

    Custom record playback resumes after a restart or chunk reload and follows player or hopper insertion and removal

Installation

  1. 1

    Check your server

    Run Paper with Java 25 or newer, built for Minecraft 26.2. Install NoteBlockAPI 1.7.0+ first.

  2. 2

    Add the JAR

    Stop the server, download Custom-Jukebox-1.2.0.jar, and place it in plugins/. When upgrading, replace the previous JAR.

  3. 3

    Start and configure

    Start the server and check the console. Review the generated configuration with the release documentation.

First command
/jukebox play

Add your NBS songs to the configured song library and open the folder-aware browser.

Commands6

CommandDescription

/jukebox reloadRescan the song library
