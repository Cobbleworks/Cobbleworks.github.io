What it does

This project is archived. Its virtual inventories are held in memory and reset on restart. The plugin targets Java 8 bytecode, but your Minecraft server and Citizens installation determine the runtime you need.

  • Citizens NPC item collection
  • Virtual inventories and death drops
  • Per-NPC filters and thief mode

Features

  • Citizens NPC item collection

    Configurable scanning and movement towards dropped items.

  • Virtual inventories and death drops

    Inventories are held in memory and reset on restart.

  • Per-NPC filters and thief mode

    Whitelist and blacklist filters, pickup toggles, and optional container stealing.

Installation

  1. 1

    Check your server

    Use a server with Citizens installed. Install Citizens first.

  2. 2

    Add the JAR

    Stop the server, download NPCItemPickup.jar, and place it in plugins/. When upgrading, replace the previous JAR.

  3. 3

    Start and configure

    Start the server and check the console. Review the generated configuration with the release documentation.

Commands9

CommandDescription
/npcpickup reloadReload plugin configuration and restart all scanning tasks
/npcpickup toggleEnable or disable all plugin functionality globally
/npcpickup statusDisplay plugin status, active task statistics, and configuration summary
/npcpickup info [npc_name]Show detailed inventory information for the nearest NPC or a named NPC
/npcpickup clear <npc_name|all>Clear the inventory of a specific NPC or all NPCs at once
/npcpickup disable <npc_id|npc_name>Disable item pickup for a specific NPC
/npcpickup enable <npc_id|npc_name>Re-enable item pickup for a specific NPC
/npcpickup thief <npc_id|npc_name>Enable thief mode — NPC will steal from nearby containers
/npcpickup unthief <npc_id|npc_name>Disable thief mode for a specific NPC
