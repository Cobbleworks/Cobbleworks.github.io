What it does

There is no configuration file. Protection starts enabled after each restart. The runtime toggle is server-wide and not persisted. Hoppers cannot extract from the protected input grid; collect crafted output from the Crafter’s output face.

Features

  • ✓Preserves one ingredient in every enabled, occupied crafter slot
  • ✓Prevents hoppers and other automated inventories from extracting Crafter ingredients
  • ✓Works with shaped and shapeless recipes without changing their outputs
  • ✓Respects slots disabled through the vanilla crafter interface
  • ✓Can be enabled, disabled, or inspected at runtime
  • ✓Requires no configuration file or external plugin

Installation

  1. Check your server

    Use Paper with the Java and Minecraft requirements listed above. No additional plugins are required.

  2. Install the release JAR

    Stop the server. Download Useful-Autocrafter-1.1.0.jar and put it in plugins/. Replace the previous JAR when upgrading.

  3. Start and check the console

    Start the server and confirm the plugin loads. Review any generated configuration and the release-specific documentation.

Your first step
/usefulcrafter

Confirm that protection is enabled, stock a Crafter, and send its output face toward your collection container.
