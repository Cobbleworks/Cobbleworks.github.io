Area Rewind

A way back for important builds.

Save named regions, compare snapshots, and restore earlier versions of your world.

What it does

Owners and trusted players control area access. Restores can be previewed and run across server ticks. WorldEdit is optional for selections and schematic exports.

  • Built-in two-point selection with a wooden hoe or look-target commands
  • Optional WorldEdit selection support and .schem export
  • Manual and scheduled backups with configurable retention
  • Restore by backup ID, latest, oldest, or a relative time

Features

  • Built-in two-point selection with a wooden hoe or look-target commands
  • Optional WorldEdit selection support and .schem export
  • Manual and scheduled backups with configurable retention
  • Restore by backup ID, latest, oldest, or a relative time
  • Undo, redo, current-state scans, and backup-to-backup comparisons
  • Owner/trusted-player access model with Bukkit permission nodes
  • Particle boundaries and restore previews
  • Per-area icons, restore speeds, and automatic backup intervals
  • Persistence for areas, backups, inventories, signs, and banner data

Installation

  1. 1

    Check your server

    Run Spigot / Paper with Java 21 or newer, built for Minecraft 1.21.8. No other plugins are required.

  2. 2

    Add the JAR

    Stop the server, download Area-Rewind-1.0.4.jar, and place it in plugins/. When upgrading, replace the previous JAR.

  3. 3

    Start and configure

    Start the server and check the console. Review the generated configuration with the release documentation.

First command
/rewind tool

Select two corners with the wooden hoe, then use /rewind save home and /rewind backup home.
