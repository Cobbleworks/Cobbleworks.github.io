What it does

Block grappling pulls the player to the hook. Catching a non-player living entity pulls it toward the player. Range, speed, boost, sound, and particles can be adjusted per player.

  • Toggle Mode
  • Block Grappling
  • Entity Grappling
  • Configurable Hook Velocity

Features

  • Toggle Mode

    Each player independently enables or disables grappling hook mode - casting while disabled behaves as a normal fishing rod with no side effects

  • Block Grappling

    When the hook lands on a block within range, the player is pulled toward that position immediately with velocity proportional to their configured pull speed and vertical boost

  • Entity Grappling

    When the hook catches a non-player living entity (mob, animal, etc.), the entity is pulled toward the player - useful for mob retrieval and custom gameplay scenarios

  • Configurable Hook Velocity

    Adjustable throw multiplier (1.0-5.0) controls how fast and far the hook travels through the air before landing

  • Configurable Pull Speed

    Adjustable pull speed (0.5-5.0) controls how quickly the player is moved toward the hook landing point

  • Vertical Boost

    Optional upward momentum (0.0-1.5) added to the pull direction, helping players clear ledges and obstacles naturally

  • Range Limit

    Each player has a maximum hook range (10-100 blocks set by the server); pulls beyond that range are cancelled with an informational message

  • Pull Cooldown

    A 250 ms gap is enforced between consecutive pulls to prevent rubber-banding or velocity stacking

  • Sound Feedback

    Optional pull sound (ENTITY_ENDER_DRAGON_FLAP) played at the player's location, toggleable per player

  • Particle Trail

    Optional CLOUD particle burst spawned at the player's location on pull, toggleable per player

  • Persistent Settings

    All per-player data is written to plugins/Hookshot/playerdata.yml on every change and on server shutdown, and reloaded on every player join

  • Reset Command

    Restores all personal settings to the server-configured defaults in a single command

Installation

  1. 1

    Check your server

    Run Spigot / Paper with Java 17 or newer, built for Minecraft 1.20.1. No other plugins are required.

  2. 2

    Add the JAR

    Stop the server, download Hookshot-1.0.1.jar, and place it in plugins/. When upgrading, replace the previous JAR.

  3. 3

    Start and configure

    Start the server and check the console. Review the generated configuration with the release documentation.

First command
/hookshot

Enable grappling mode, hold a fishing rod, and cast toward a block within your configured range.
